- Spring Security가 무엇인가?

  Spring Security(스프링 시큐리티)란, 스프링 기반 애플리케이션에서 보안(인증과 인가, 공통 공격 방어)을 쉽고 강력하게 처리할 수 있도록 지원하는 프레임워크.

  자바 웹 애플리케이션에서 보안을 직접 구현하려면 필터(Filter)나 인터셉터(Interceptor)를 짜고, 세션/쿠키를 검증하는 등 복잡한 코드를 매번 작성해야 함.

  ⇒ 스프링 시큐리티가 이러한 핵심 보안 표준들을 미리 다 구현해 두고 제공하는 역할을 함.

  **스프링 시큐리티가 해주는 주요 기능들**

    - **다양한 인증 방식 지원**: 미션에서 했던 ID/PW기반 로그인 뿐만 아니라, JWT나 OAuth를 지원.
    - **비밀번호 암호화**: 미션에서의 PasswordEncoder처럼 비밀번호를 안전하게 단방향 해시화 하여 DB에 저장할 수 있도록 함.
    - **메서드 레벨 보안**: URL경로를 통한 API단위 뿐만 아니라, @PreAuthorize("hasRole('ADMIN')") 와 같은 어노테이션을 통해 메서드 단위로도 권한이 있는 사람만 메서드를 실행할 수 있도록 함.
    - **웹 취약점 및 공격 방어**: CSRF(Cross-Site Request Forgery), XSS(크로스 사이트 스크립팅) 등의 공격을 방어.

- 인증(Authentication)vs 인가(Authorization)

  인증: 신원확인.

  인가: 권한확인.

  ⇒ 특정 사람에게 어떤 권한이 있는지를 확인하려면 그 사람이 누구인지 부터 알아야하기 때문에 반드시 인증이 먼저 이루어진 후에 인가가 이루어진다.


  **실패 시 응답:** `401 Unauthorized` (미인증)     /      `403 Forbidden` (권한 부족)

- Stateful vs Stateless

  ‘상태’를 유지 하느냐 안하느냐에 따라 Stateful / Stateless 로 나뉨.

  **Stateful(상태 유지)**은 서버가 클라이언트의 상태를 직접 기억하는 방식. 요청의 맥락이 이어지기 때문에 하나하나 다 설명할 필요가 없음. (전통적인 세션 기반 로그인, FTP, TCP 연결이 이에 해당.)

  **Stateless(무상태)**는 서버가 아무것도 기억하지 않는 방식. 모든 요청은 그 자체로 완결되어야 하며, 클라이언트가 매번 필요한 정보(보통 JWT 토큰)를 담아 보냄. (HTTP, REST API, GraphQL이 이에 해당.)

  ### **Stateful 장단점**

    - 컨텍스트 유지 → 빠른 응답 🍅
    - 클라이언트 요청 간결 🍅
    - 서버 장애 시 세션 소멸 🍆
    - 수평 확장(스케일 아웃) 어려움 🍆
    - 로드밸런서 sticky session 필요 🍆
      ⇒ Stateful서버를 여러대 두면 사용자 세션정보는 특정 서버에만 존재하기 때문에 해당 사용자를 항상 그 서버로만 보내라고 로드밸런서에게 지시하게됨.

  **[ 그럼에도 Stateful을 사용하는 이유 ]**

    - **실시간 양방향 통신:** HTTP같은 경우는 클라이언트가 먼저 물어봄. 하지만, 예를 들어 온라인 게임 같은 경우, 서버가 먼저 메시지를 보내는 상황이 존재. ⇒ 클라이언트를 기억해야함.
    - **대용량 파일 전송 / 스트리밍:** 오랜시간 파일을 전송 하다가 중간에 다른 서버로 바뀌면 처음부터 해야함. ⇒ 현재 어느 파일까지 전송되었는지를 서버가 기억.
    - **긴 계산 작업 / 트랜잭션:** DB 트랜잭션은 "BEGIN → 작업들 → COMMIT" 전체가 같은 연결에서 이루어져야 원자성이 보장됨. 마찬가지로 중간에 서버 바뀌면 안됨.
    - **낮은 지연이 생명인 시스템:** 온라인 게임, 고빈도 금융 거래(HFT), 자율주행 등은 매 요청마다 JWT 검증하고 DB 조회하는

  ### **Stateless 장단점**

    - 수평 확장 쉬움 🍅
    - 서버 장애 복구 간단 🍅
    - 캐싱 용이 (REST 원칙) 🍅
    - 요청마다 데이터 중복 전송 🍆
    - 토큰/세션 관리 클라이언트 부담 🍆
